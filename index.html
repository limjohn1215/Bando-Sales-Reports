How to add a new week
Go to the Data tab of the Google Sheet → add 4 new rows at the bottom (one per channel) → use the same Week Label text for all 4 (e.g. "Jul 8-12, 2026") → fill in Orders, Gross Sales, Discount, Tax, Tips, Net Payout → leave a cell as 0 if unknown, and use Notes for anything unusual. This dashboard updates automatically — no formulas to touch here.
